# ASCII Knight

An animated ASCII knight in a windswept field, rendered with vanilla JavaScript and HTML5 Canvas.

## Features

- Animated red fabric and flowing cloak
- Subtle breathing and swaying movements
- Wind-driven grass and floating particles
- Soft glow effects
- Responsive fullscreen display
- No external dependencies or build tools

## Run locally

Download or clone this repository, then open `index.html` in your browser.

## Customize

Adjust the constants near the top of `index.html` to change animation speed, wind strength, movement, colors, and glow.

## Built with

- HTML
- CSS
- JavaScript
- Canvas 2D API
